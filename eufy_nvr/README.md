# Eufy NVR Local — experimental

By Efficient X (EFX). Guided setup and shared fixed/tracking camera tiles for
Eufy PoE NVRs, targeting S4/T8N00. Fresh-install live-camera acceptance is pending.
Eufy internet sign-in and signalling are required; do not assume a fully offline
or LAN-only connection. Keep an existing working video engine until tested.
